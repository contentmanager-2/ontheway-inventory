# OnTheWay Inventory

Веб-система учёта вещей, продаж и расходов магазина брендовой одежды OnTheWay.

## Что уже работает

- каталог вещей и статусы;
- добавление новых карточек;
- фиксация продаж и прямых затрат;
- умный ввод продажи обычной фразой;
- журнал расходов;
- финансовый обзор и месячные показатели;
- адаптация под телефон;
- общая синхронизация данных через Supabase с локальной резервной копией;
- вход по email и паролю с любого телефона или компьютера;
- импорт JSON, собранного локальным помощником со страницы профиля Авито.
- нормализация Fear Of God Essentials: рекламные дубли не превращаются в остатки;
  система создаёт 54 варианта (4 модели, 3 цвета и допустимые размеры).
- карточки сгруппированы по папкам брендов;
- редактирование карточки, количества, цвета, размера, цен и статуса;
- единая матрица остатков Essentials по модели → цвету → размеру;
- архив для проданных вещей и безопасное окончательное удаление тестовых карточек.

## Запуск без установки

Откройте `index.html` в браузере. Для корректной работы модулей лучше запустить локальный HTTP-сервер:

```bash
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Важно

Сайт подключён к Supabase. При первом входе существующий локальный каталог переносится в общую базу, после чего изменения синхронизируются между устройствами. `localStorage` остаётся резервной копией на случай временной потери связи.

Публичный `SUPABASE_PUBLISHABLE_KEY` находится в `config.js` — это штатно для браузерного приложения. Ключи `service_role`, secret key и пароль базы нельзя добавлять в GitHub.

Секреты Supabase и будущей интеграции Авито нельзя добавлять в GitHub. Файлы `.env` исключены через `.gitignore`.

## Следующие этапы

1. Supabase: база, авторизация, фотографии и резервное копирование.
2. Импорт текущих 300–400 вещей из CSV.
3. История изменений и роли сотрудников.
4. Серверный ИИ-разбор сообщений и фотографий.
5. Официальный Avito API при переходе на подходящий профессиональный тариф.

## Импорт из текущего профиля Авито

В папке `tools/avito-capture-extension` находится локальный помощник Chrome. Он не открывает объявления и не выполняет фоновые запросы: считывает только карточки, уже показанные на странице профиля, пока пользователь самостоятельно прокручивает каталог. Подробная инструкция находится в README внутри папки расширения.

Для Essentials объявления хранятся отдельно как источники. Товарный каталог строится
по матрице: худи XS–XL, футболки XS–XL, штаны S–XL и шорты S–XL; цвета — Light
Oatmeal, Dark Oatmeal и Stretch Lim. Закупочная цена и фактический остаток не
угадываются из объявления и остаются на подтверждение владельцу.

# OnTheWay · Avito Capture

Локальное расширение Chrome для первоначального переноса каталога. Оно не открывает объявления и не делает фоновых запросов к Авито. Расширение читает только карточки, которые уже отрисованы на странице профиля в браузере пользователя.

## Установка

1. Откройте в Chrome `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку `tools/avito-capture-extension`.
5. После установки обновите страницу `https://www.avito.ru/brands/ontheway/items`.

## Сбор

1. На странице профиля нажмите значок расширения.
2. Нажмите «Начать сбор».
3. Закройте окно расширения и самостоятельно прокручивайте каталог.
4. Расширение сохранит только появившиеся на экране карточки и уберёт дубликаты по ID Авито.
5. Откройте расширение снова и нажмите «Скачать JSON».
6. В системе OnTheWay откройте «Вещи» → «Импорт из Авито» и выберите скачанный файл.

Импортированные карточки получают статус «Подготовка», потому что закупочная стоимость отсутствует в Авито. Перед продажей её нужно заполнить.
